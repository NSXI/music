# نَوى · Nawa لأندرويد

نسخة مستقلة للجوال والتابلت من مشروع نَوى، بمحرك Go محلي وواجهة التطبيق وثيماته. لا تحتاج تشغيل الكمبيوتر. ملف Samsung ARM64 نفسه مهيأ لـ Galaxy Tab S10 Ultra وGalaxy S10+ وأجهزة ARM64 الأخرى على Android 9/API28 فما فوق. الاختبارات أُجريت داخل محاكي Android 15، وليس على جهازَي Samsung فعليين.

## البداية

1. ثبّت `Nawa-Android-Samsung-arm64.apk`. عند طلب النظام، اسمح بالتثبيت من مدير الملفات الذي فتحته.
2. اختر العربية أو English من أعلى التطبيق. زر ☰ يفتح كل صفحات التطبيق؛ الجوال يعرض أيضًا شريط تنقل سفلي، والتابلت يعرض شريطًا جانبيًا.
3. أضف ملفات أو مجلدًا. تُنسخ الملفات المختارة إلى مكتبة التطبيق، وتبقى الأصول في مكانها. الاستيراد يشمل المجلدات الفرعية والتقدم والإلغاء وإعادة الفحص ومنع التكرار بالمحتوى.
4. من «الإعدادات والمصادر» تستطيع استيراد خط TTF/OTF، وتنزيل نموذج التوقيت الذي حجمه 147,951,465 بايت، وتصدير مكتبتك. خطوط أندرويد المتاحة والخطوط المستوردة لها معاينة منفصلة للكلمات والترجمة.
5. زر اختيار مجلد التنزيل يستخدم منتقي مجلدات أندرويد. عند اختياره، تُصدّر نسخة من التنزيلات الجديدة إليه تلقائيًا مع الغلاف والكلمات المتاحين وقت اكتمال التنزيل. الملفات الموجودة لا تُستبدل. زر «تصدير المكتبة» ينسخ الملفات الحالية إلى مجلد تختاره. ستبقى النسخة الأساسية داخل التطبيق.

## تحديث أندرويد من داخل التطبيق

من الإعدادات افحص التحديثات، ثم نزّل الإصدار الجديد داخل نَوى. يدعم التنزيل الإيقاف والاستئناف، ويُرفض APK إذا اختلفت بصمته أو توقيعه أو اسم التطبيق أو الإصدار أو معمارية المعالج. زر تثبيت التحديث يستخدم FileProvider ونافذة تثبيت أندرويد؛ قد يطلب النظام السماح لنَوى بتثبيت التطبيقات، وتبقى موافقتك على التثبيت مطلوبة. لا تحذف النسخة الحالية؛ الترقية بنفس المعرف ومفتاح التوقيع تحفظ بياناتها. رابط الإصدار الافتراضي هو GitHub Releases لمستودع NSXI/music، ويحتاج نشر ملف التحديث والحزمتين أولًا.

## اختلافات أندرويد وحدود الدقة

- الترجمة تستخدم **ML Kit على الجهاز** بدل محرك Windows. تحتاج الإنترنت لتنزيل نموذج اللغة أول مرة، ثم تترجم محليًا وتحفظ النتيجة. يدعم التطبيق 18 لغة في واجهته الحالية، ومنها العربية والإنجليزية واليابانية والروسية. الترجمة قابلة للمراجعة؛ ليست مضمونة بلا أخطاء.
- التوقيت المحلي يستخدم **Whisper.cpp** ونموذج base متعدد اللغات. يجب تنزيل النموذج من إعدادات أندرويد أولًا؛ يتحقق التطبيق من SHA-256 قبل اعتماده. يدعم فحص ملفات حتى 30 دقيقة. تُطابق الكلمات الأصلية مع توكنات التعرف دون تغيير نصها. إذا لم تتطابق كل الكلمات أو كانت الأزمنة غير صالحة، لا تُستبدل الكلمات الأصلية. النتائج الصحيحة تُعرض كمقترح يحتاج مراجعة وتطبيقًا. تحريك الحروف داخل زمن الكلمة بصري، وليس قياسًا صوتيًا لكل حرف. الغناء والموسيقى المختلطة قد لا يتعرف عليهما النموذج جيدًا.
- الترجمة تتبع توقيت الأصل وشكله، ولا تنشئ توقيت كلام مستقلًا غير مقاس.
- مصدر الملف يحدد أعلى جودة متاحة فعلًا. التنزيل من مصدر lossy لا يصبح lossless بتحويل الامتداد. ملفات FLAC/PCM تعرض دقة المصدر المتحققة؛ تحويل صيغة للتشغيل لا يغيّر وصف المصدر.
- الإخراج العائم مفعّل في Media3 عندما يدعمه النظام. معدل DAC الفعلي وDolby وHi-Res وSpatial Audio تعتمد على جهاز Samsung، سماعاته، إعدادات النظام ومسار الصوت. التطبيق لا يتضمن ترخيص Dolby مستقلًا ولا يضمن إخراجًا bit-perfect.
- منزلقات EQ العشرة تُطابق نطاقات Equalizer الفعلية التي يوفرها الجهاز. الصدى يستخدم مؤثر النظام؛ الاتساع يستخدم Virtualizer عند توفره، وليس مصفوفة ستيريو Windows نفسها. أسماء التحكم ومداهما مشتركة، وقد تختلف النتيجة الصوتية بين الأجهزة.
- تُفك الصيغ التي لا يدعمها Media3 مباشرة بواسطة FFmpeg عند الإمكان. MIDI يحتاج مُركِّبًا وساوندفونت ولا يُعرض كتنزيل صوتي مدعوم في بحث Commons. الملفات التالفة أو المشفرة لا يُضمن تشغيلها.
- Android لا يمنح التطبيق وصولًا إلى كل خطوط السمات الخاصة في النظام. استورد TTF/OTF إذا لم يظهر خط معين. استخدم Android System WebView حديثًا لاستفادة كاملة من الرسوم وCSS.
- Spotify يتطلب Client ID صالحًا وتسجيل دخولك إذا احتاج المصدر صلاحية. لم تُضمّن حسابات أو مفاتيح أو خوادم TIDAL عامة مضمونة. لا يجري تجاوز حماية الملفات. توفر الخدمات والملفات والجودات يتغير حسب المصدر.
- الشفافية الزجاجية داخل نافذة التطبيق. إظهار خلفية نظام أندرويد عبر التطبيق ليس مكافئًا لشفافية نافذة Windows.

## البناء

المتطلبات: Go1.26، JDK17، Gradle8.11.1، Android SDK35، Build Tools35.0.0، NDK28.2.13676358 وCMake3.22.1. اضبط `ANDROID_HOME` و`JAVA_HOME` ثم:

```powershell
./build-core.ps1 -Abi arm64-v8a
./gradlew.bat -PnawaAbis=arm64-v8a :app:assembleDebug
```

لإصدار موقّع اضبط `NAWA_SIGNING_STORE` و`NAWA_SIGNING_PASSWORD` لمخزن PKCS12 بمفتاح alias=`nawa`، ثم شغّل `:app:assembleRelease`. مفتاح إصدار المستخدم محفوظ خارج مجلد المصدر العام. لا تُضمّن المفتاح أو ملفات البيانات في أرشيف المصدر.

المصدر الأصلي لويندوز وبياناته لم يُنقلا إلى APK. لا توجد ملفات EXE أو مكتبة المستخدم أو مفاتيحه داخل حزمة أندرويد. تفاصيل الاختبار في `TESTING.md` و`VALIDATION.json`، وإشعارات المصادر في `THIRD-PARTY.md`.
