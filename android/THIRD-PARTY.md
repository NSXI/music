# Android dependencies and source notices

This is an independent Android port of the user's Nawa project. Existing desktop-core and visual-asset notices are retained under `third-party/windows-core-licenses` and `app/src/main/assets/theme-logos`. Those retained notices do not imply that Windows binaries or the NLLB model are included in the APK.

- **Go** 1.26, BSD-style license: https://go.dev/LICENSE ; `golang.org/x/net` and `golang.org/x/text` notices are retained with the core source.
- **AndroidX WebKit, Activity, Core, DocumentFile, Media3**: Apache2.0, https://android.googlesource.com/platform/frameworks/support/ ; Media3 sources https://github.com/androidx/media . Background session guidance: https://developer.android.com/media/media3/session/background-playback . Stable local WebView origin: https://developer.android.com/develop/ui/views/layout/webapps/load-local-content . Float-output API: https://developer.android.com/reference/androidx/media3/exoplayer/DefaultRenderersFactory . Versions are pinned in the Gradle file.
- **youtubedl-android** library and FFmpeg packages 0.18.1: https://github.com/yausername/youtubedl-android and Maven coordinates `io.github.junkfood02.youtubedl-android`. The maintained build includes native Python, FFmpeg and QuickJS packages. Source/build provenance: https://github.com/JunkFood02/youtubedl-android . Preserve upstream notices for all bundled native components; FFmpeg build licensing applies to distribution of its binary, independently of the app's Go core.
- **yt-dlp**: bundled official zipimport executable2026.10.26, https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26 . Unlicense for yt-dlp; bundled EJS/components retain ISC/MIT notices inside the verified archive. Provenance/size/SHA256 in `app/src/main/assets/extractor/manifest.json`. Python3.12 and offline QuickJS/EJS are used; no runtime download of solver scripts.
- **AMLL TTML DB**: https://github.com/amll-dev/amll-ttml-db , CC0-1.0 repository declaration. On-demand contributor timing, with local cache; no lyric corpus bundled. Lyrics and recordings can have separate rights. TTML timing segments and public NetEase YRC responses preserve actual provided timestamps; character interpolation is not phoneme measurement.
- **FFmpeg**: https://ffmpeg.org/legal.html and https://github.com/FFmpeg/FFmpeg . Corresponding Android build scripts/patches are in the youtubedl-android upstream build pipeline. The source ZIP includes Nawa's integration and Whisper source; it does not claim to include every upstream FFmpeg/Python source tarball.
- **Whisper.cpp** v1.9.5: MIT, https://github.com/ggml-org/whisper.cpp/tree/v1.9.5 . Corresponding native source including ggml is vendored under `native/whisper`; its LICENSE is retained. - **ML Kit Translate and Language Identification**: Google SDK terms, https://developers.google.com/ml-kit/terms . Translation API/model management: https://developers.google.com/ml-kit/language/translation/android . Models are downloaded through ML Kit when requested and do not ship in this APK.
- Game logos and the independent visual interpretations retain their existing source attributions in `theme-logos`. No affiliation with Sony, FromSoftware, Disney, Square Enix, Atlus or Sega is implied.

No user audio, cached lyric bodies, provider credentials, signing secrets or language/timing models are in the distributed source ZIP. The optional test speech was generated locally and is not part of the APK.

Android update installation uses the system package installer, with a non-exported FileProvider restricted to the private update cache. Official APIs: https://developer.android.com/reference/androidx/core/content/FileProvider and https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls() . Downloads are verified before handing a read-only content URI to Android; system confirmation remains required.

Approved game theme fonts and artwork are shared under app/src/main/assets/game-themes, with OFL notices, Televo author notes and exact source/hash provenance. Nawa Reload uses Barlow as a visual alternative, not the licensed original Rodin. Adobe Garamond is local-only on desktop and is not in this APK; Android uses the bundled EB Garamond fallback.
